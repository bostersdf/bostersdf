# Привет! 👋

Я начинающий разработчик игр, осваивающий Unity и C#. Мой путь начался с мобильной разработки на Flutter, но страсть к созданию игр привела меня в увлекательный мир геймдева.

## 🎮 Мои направления в игровой разработке

### 🎯 Текущие цели:
1. **5v5 соревновательный шутер** - изучение сетевого кода и баланса
2. **Сталкер-прототип** - атмосферный синглплеер с выживанием
3. **Глубокое изучение C#** - освоение продвинутых паттернов и оптимизации

### 🔧 Технологии которые изучаю:
- **Unity Engine** - создание 3D игр
- **C#** - игровая логика и системы
- **Universal Render Pipeline** - современная графика
- **Git & GitHub** - контроль версий

## 🛠️ Мой технический бэкграунд

### 📱 Мобильная разработка (опыт):
- **Flutter** - кроссплатформенные приложения
- **Dart** - основной язык

### 🎮 Игровая разработка (осваиваю):
- FPS-контроллеры и управление камерой
- Сетевая синхронизация игроков

## 📚 Мой подход к обучению

### Методика:
- **Практика через создание** - учусь делая реальные проекты
- **Анализ успешных игр** - разбираю механики любимых проектов
- **Постепенное усложнение** - от простых прототипов к комплексным системам

### Принципы:
1. **Код должен быть читаемым** - даже если это прототип
2. **Оптимизация на ранних этапах** - хорошая архитектура с самого начала
